# Garuda-360
🦅 Welcome to GARUDA 360 — Every Topic. Every Angle. We make the complex simple through cinematic visuals, fact-checked storytelling and engaging educational content. Real knowledge. Zero hype.


A static brand site with no build step and no dependencies.

## Files
- `index.html`: home page (hero, about, channels, values, craft, contact)
- `privacy.html`, `terms.html`: legal pages, also used by the Google OAuth consent screen
- `css/style.css`, `js/main.js`, `assets/`
- **Settings** (channel links and contact email) are at the top of `js/main.js`.

## Publish (GitHub Pages)
Repo: https://github.com/esatyatej1/Garuda-360
1. Push these files to the root of the `main` branch.
2. In the repo, go to Settings → Pages, set Source to "Deploy from a branch" with `main` / `(root)`, and click Save.
3. The site goes live at https://esatyatej1.github.io/Garuda-360/
