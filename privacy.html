Privacy Policy

Last updated: 26 November 2026

This policy explains how Garuda 360 and Garuda Vision ("we", "us") handle information on this website and in the Garuda 360 publishing app, the private tool we use to publish videos to our own YouTube channels.

In short: this website collects nothing. Our publishing app only touches YouTube channels we own, and we never sell or share Google user data.

01This website

This is a static website. It uses no cookies, analytics, trackers, advertising or forms, and it doesn't collect personal information. Fonts are loaded from Google Fonts, which may log basic technical data such as your IP address under Google's Privacy Policy. Links to YouTube are covered by YouTube's own policies.

02The publishing app

The app is an internal tool. It isn't offered to the public, and only the owners of the Garuda 360 and Garuda Vision channels sign in to it with Google OAuth.

03Google user data we access

When a channel owner signs in, the app requests these YouTube Data API scopes:

  • youtube.upload: upload videos to the signed-in channel.
  • youtube.readonly: read the channel's name, ID, videos and playlists so each upload goes to the right place.
  • youtube.force-ssl: manage playlists, captions and video details on that channel.

04How we use it

We use this data only to publish and organise videos on our own channels. We do not sell, rent or share Google user data, use it for advertising, or use it to train AI or machine-learning models. Humans read it only when that's needed to fix a problem or for security.

Our use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

05Storage and security

The OAuth token is stored only on our own computer, in a local file that's never uploaded or shared. All communication with YouTube uses encrypted HTTPS.

06Retention and deletion

We keep the token only while uploads need it. Access can be revoked at any time from Google Account permissions, and we delete the local token file when access is revoked or no longer needed.

07YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

08Children

This website and app aren't directed at children under 13, and we don't knowingly collect their information.

09Changes

If this policy changes, we'll update the date at the top of this page.

10Contact

For questions about this policy, email us.
